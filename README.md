# HTML_TO_PDF_CLIENT

A from-scratch, **client-side**, vector-fidelity HTML→PDF rendering library.

```js
import { htmlToPdf } from './src/index.js';
const bytes = await htmlToPdf(htmlString, {
  viewport: { width: 1123, height: 794 },  // A4 landscape in CSS px
});
// → Uint8Array of valid PDF 1.7
```

The PDF contains real selectable text, real clickable hyperlinks, embedded
subsetted Inter font, vector geometry — no canvas rasterization, no third-party
PDF generators. See **CONSTRAINTS.md** for the no-dependency rules.

## Architecture

The lib uses the **host browser's native layout engine** (`getBoundingClientRect` +
`getComputedStyle` on a hidden iframe) rather than reimplementing CSS layout from
scratch. See **CLAUDE.md "Architectural decision"** for why this is consistent
with "from scratch, no third-party PDF lib".

```
HTML string
  │
  ▼  walker.js (hidden iframe, browser layout)
flat list of render boxes  (style + geometry per element)
  │
  ▼  painter.js
PDF content stream         (paths, text Tj/TJ, link annotations)
  │
  ▼  core/pdf.js
PDF document bytes         (xref, catalog, fonts, images, shadings)
```

### Modules (`src/`, ≈ 2.0 K LOC)

```
src/
├── index.js                  → public API: htmlToPdf(html, opts) → Uint8Array
├── core/
│   ├── pdf.js                → PDF writer: indirect objects, xref, content streams,
│   │                           ops q/Q/rg/RG/re/f/S/BT/ET/Tf/Tm/Tj/TJ/W/n/m/l/c/sh/Do/cm/d/gs,
│   │                           axial shading dict, link annotations, image XObjects, ExtGState
│   ├── fonts/
│   │   ├── sfnt.js           → minimal TTF/OTF parser (head, hhea, hmtx, maxp, cmap fmt 4/12)
│   │   └── embed.js          → Type 0 + CIDFontType2 + Identity-H + ToUnicode CMap +
│   │                           FlateDecode-compressed FontFile2
│   └── images/
│       └── jpeg.js           → JPEG passthrough as XObject /DCTDecode
├── dom/
│   ├── walker.js             → iframe-based layout, captures style + Range rects
│   └── utils.js              → parseColor (rgb/rgba/color(srgb)/hex), parsePx
└── render/
    ├── painter.js            → emits PDF ops per box: backgrounds, borders (with
    │                           radius and dash), gradients (axial), text (hex GIDs
    │                           with letter-spacing via TJ), opacity (ExtGState ca/CA),
    │                           per-character font fallback (Latin + Greek)
    └── svg.js                → SVG primitives: rect, line, circle, ellipse, text
                                via getScreenCTM() per element
```

### Test loop (`scripts/`)

```
scripts/loop.mjs  ← orchestrator
  │
  ├── render-with-lib.mjs   → spawn Playwright Chromium, load demo/run.html,
  │                           call lib in-page, return PDF bytes
  ├── pdf-to-png.mjs        → rasterize lib output via pdfjs-dist + @napi-rs/canvas
  ├── diff.mjs              → pixelmatch vs reference/<fixture>.png
  └── audit.mjs             → pdfjs.getAnnotations() + getTextContent() + signature scan
                              for /FontFile2 + Inter embedding
```

## What's next (post-session)

1. Embed individual Inter character subsets matching only used glyphs (for size — would shrink 250 KB PDFs to ~30 KB).
2. PNG decoding for image embedding (currently JPEG-only).
3. OpenType GSUB processing for icon fonts (Material Symbols ligatures).
4. CSS Grid / multi-column layout for elements where the iframe layout misses something.
5. Better baseline calculation per font (currently empirical 0.80 ratio).
