HTML → PDF — Documentation

Convertisseur 100% client-side, sans serveur, sans jsPDF/pdf-lib/html2canvas. Voir README.md et CONSTRAINTS.md pour le détail technique.

1Démarrer l'outil

Double-clique sur convert.bat (à la racine du projet). Il lance un petit serveur local et ouvre automatiquement la page de conversion dans ton navigateur.

Ferme la fenêtre console noire pour arrêter le serveur.

2Convertir un fichier

  • Glisse-dépose un fichier .html dans la zone prévue (ou clique pour le choisir).
  • Choisis un format de page (A4, Letter, portrait/paysage, ou une taille personnalisée).
  • Clique Convertir → PDF, vérifie l'aperçu, puis Télécharger.

Le PDF généré contient du vrai texte vectoriel (sélectionnable, cherchable), les polices utilisées, et les liens cliquables — jamais une image de la page.

3Forcer un saut de page

nouveau

Par défaut, un document plus haut qu'une page est découpé automatiquement (sans jamais couper une ligne de texte). Pour forcer un saut de page à un endroit précis, ajoute un marqueur dans le HTML :

<div class="page-break"></div>

Tout ce qui suit ce marqueur commence sur une nouvelle page. Le marqueur peut être un <div> vide placé n'importe où entre deux sections.

Variantes acceptées (au choix) :

  • class="pagebreak" ou class="break-page" (alias de page-break)
  • data-page-break comme attribut sur n'importe quel élément
  • CSS standard : style="break-before: page" ou style="page-break-before: always"
Le marqueur définit où la nouvelle page commence : place-le juste avant le contenu qui doit démarrer la page suivante.

4Exemple complet

<h1>Section 1</h1>
<p>Contenu de la première page…</p>

<div class="page-break"></div>

<h1>Section 2</h1>
<p>Ce texte commence sur une nouvelle page.</p>
